# MouseSaver
🖱️ MouseSaver - by Generic Gamer

MouseSaver is a small utility that remembers your mouse position after 1 second of stillness, 
and lets you snap it back instantly using Ctrl + Alt + M.

🎮 Features:
- Automatically saves mouse position when idle
- Press Ctrl + Alt + M to teleport your mouse back!
- Tray toggle: Right-click tray icon to enable/disable
- Plays a sound when toggled
- Clean, lightweight, and easy to use

🔧 How to Use:
1. Run MouseSaver.exe
2. Let it chill in the tray
3. When your mouse stops moving for 1 second, it saves the position
4. Hit Ctrl + Alt + M anytime to jump your mouse back!

📌 Tray Options:
- Toggle MouseSaver (turns the tracking on/off)
- Exit (closes the app)

🛠️ Installation Notes:
- If you selected "Run at startup", a shortcut was placed in your Startup folder.
- You can also drag MouseSaver.exe anywhere you like.

📁 Included Files:
- MouseSaver.exe (main app)
- toggle.wav (sound played when toggled)
- icon.ico (used for the tray icon)
